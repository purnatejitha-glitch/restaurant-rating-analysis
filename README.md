Restaurant Ratings Analysis

📌 Project Overview

This project explores restaurant ratings data to understand customer satisfaction, rating distributions, and voting patterns. The analysis helps identify common restaurant ratings and calculate the average number of votes received by restaurants.

🎯 Objectives

- Analyze the distribution of aggregate restaurant ratings.
- Identify the most common rating range.
- Calculate the average number of votes received by restaurants.
- Present insights using data visualization.
- Support better understanding of customer preferences.

🛠️ Tools & Technologies

- Tableau
- Microsoft Excel
- Data Visualization
- Exploratory Data Analysis (EDA)

📊 Key Analysis

1. Aggregate Rating Distribution

Visualize restaurant ratings to identify the most common rating range and understand overall customer satisfaction.

2. Average Votes Analysis

Calculate the average number of votes received by restaurants to explore customer engagement.

💡 Expected Insights

- Identify the most frequent restaurant rating range.
- Understand average voting activity.
- Discover patterns in restaurant ratings and customer engagement.

📁 Project Structure

- "Dataset/" — Restaurant ratings dataset
- "Visualizations/" — Charts and dashboard screenshots
- "README.md" — Project documentation

🚀 Conclusion

This project demonstrates how data visualization can be used to analyze restaurant ratings and voting patterns, turning raw data into meaningful business insights.
